Core Architecture

The Cooperative Multitasking Paradigm

Why delay() paralyzes embedded single-core CPUs and how timestamp subtraction enables silky multi-tasking.

⛔

The delay() Trap

delay() traps the program counter in a tight spin-loop, freezing all digital inputs, serial buffers, and motor controllers.

⏱️

Hardware Clock Wristwatch

Timer0 increments an internal 32-bit tick counter every millisecond. Querying millis() allows the CPU to check time without pausing.

🧩

Modular Task Structs

Packaging interval thresholds and timestamps into state structures provides a lightweight, deterministic scheduler without RTOS overhead.

The Non-Blocking Equation: if (currentMillis - previousMillis >= interval) { previousMillis = currentMillis; ... }. This subtraction is mathematically immune to 49.7-day integer rollover!

Firmware Laboratory

Microcontroller Firmware Implementation

Moving from basic millis() timing to structured multi-task scheduling.

timers_basic.ino
/* Blink Without Delay Fundamental Pattern */

const int LED_PIN = 13;
int ledState = LOW;

unsigned long previousMillis = 0;
const long interval = 1000; // 1 second

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  unsigned long currentMillis = millis();

  // Check if interval has elapsed
  if (currentMillis - previousMillis >= interval) {
    previousMillis = currentMillis;

    ledState = !ledState;
    digitalWrite(LED_PIN, ledState);
  }

  // CPU is completely free to read other sensors here!
}

🔎 Register & API Analysis

1
struct TaskTimer

Encapsulates previousMillis and interval, making it trivial to declare dozens of independent tasks.

2
Timer0 Hardware Interrupt

ATmega328P prescaler triggers TIMER0_OVF_vect every 1.024ms, incrementing the internal 32-bit tick count.

3
Unsigned Subtraction

Ensures that even when time wraps around from 4,294,967,295 to 0, delta math remains accurate.

4
Independent Frequencies

Task 1 (4Hz) and Task 2 (1Hz) share zero state and run completely asynchronously.

5
Deterministic Responsiveness

Input events can be serviced in <5 microseconds without waiting for long delay loops to complete.

timers.ino · production cooperative scheduler
/*
 * Module: Non-Blocking Concurrent Timers & Multitasking
 * Features: Multi-task cooperative struct scheduler
 */

struct TaskTimer {
  unsigned long previousMillis;
  unsigned long interval;
};

TaskTimer taskFast      = {0, 250};   // 4Hz toggle (250ms)
TaskTimer taskSlow      = {0, 1000};  // 1Hz toggle (1000ms)
TaskTimer taskTelemetry = {0, 2000};  // Report every 2.0s

const int PIN_FAST = 11;
const int PIN_SLOW = 12;

bool stateFast = false;
bool stateSlow = false;

void setup() {
  pinMode(PIN_FAST, OUTPUT);
  pinMode(PIN_SLOW, OUTPUT);
  Serial.begin(9600);
  Serial.println(F("Cooperative Multitasking Engine Online."));
}

void loop() {
  unsigned long now = millis();

  // Task 1: Fast Flash
  if (now - taskFast.previousMillis >= taskFast.interval) {
    taskFast.previousMillis = now;
    stateFast = !stateFast;
    digitalWrite(PIN_FAST, stateFast);
  }

  // Task 2: Slow Flash
  if (now - taskSlow.previousMillis >= taskSlow.interval) {
    taskSlow.previousMillis = now;
    stateSlow = !stateSlow;
    digitalWrite(PIN_SLOW, stateSlow);
  }

  // Task 3: Telemetry Stream
  if (now - taskTelemetry.previousMillis >= taskTelemetry.interval) {
    taskTelemetry.previousMillis = now;
    Serial.print(F("[UPTIME] "));
    Serial.print(now / 1000);
    Serial.print(F("s | Fast LED: "));
    Serial.print(stateFast ? "ON" : "OFF");
    Serial.print(F(" | Slow LED: "));
    Serial.println(stateSlow ? "ON" : "OFF");
  }
}
