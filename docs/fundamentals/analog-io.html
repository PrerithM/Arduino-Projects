Core Architecture

The Physical Signal Model

A potentiometer functions as an adjustable resistive voltage divider. Rotating the shaft sweeps the wiper contact across a resistive track to scale output potential.

🎛️

Resistive Divider

Dividing 5V across a 10kΩ carbon track yields a continuous analog output voltage between 0.00V and 5.00V on the center wiper pin.

⚡

Analog Pin A0

Multiplexed directly into the internal Successive Approximation Register (SAR) ADC channel of the ATmega328P.

🔢

10-Bit Quantization

Transforms the incoming 0V–5V continuous potential into discrete integers from 0 to 1023 (1024 distinct voltage steps).

Signal Processing Chain: Mechanical Rotation → Variable Resistance → Scaled Voltage (0–5V) → 10-Bit ADC Conversion (0–1023) → Moving Average Filter → Serial Telemetry.

Mathematical Theory

ADC Quantization Mathematics

How the microcontroller converts analog voltage into digital registers.

The ATmega328P integrates an internal 10-bit successive-approximation ADC:

2¹⁰ = 1024 States

Quantization bins span sequentially from 0 to 1023.

0 (0.000V)512 (2.502V)1023 (4.995V)
Vin = (ADCval × Vref) / 1023.0

Example at mid-scale (512):

512 × 5.0V / 1023.0 ≈ 2.502 V

Yielding an effective quantization granularity of 4.887 mV per count.

Digital Signal Processing

Moving Average Noise Filtering

Raw breadboard circuits pick up ambient electromagnetic interference (EMI). A circular 10-sample rolling buffer stabilizes telemetry without lag.

Unfiltered Raw Stream (Noisy)

High-frequency noise causes rapid bit-toggling on the least significant bits (LSB).

10-Sample Moving Average (Smoothed)

Running sum divided by sample count eliminates thermal jitter.

Algorithmic Advantage: Subtracting the oldest item from running sum and adding the newest sample operates in constant O(1) execution time without loop overhead.
Firmware Laboratory

Microcontroller Firmware Implementation

From minimal sampling to production-grade filtered stream.

analog_basic.ino
/* Read an analog input and compute real-world voltage */

const int ANALOG_PIN = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  // Query 10-bit Successive Approximation ADC
  int rawValue = analogRead(ANALOG_PIN);

  // Scale discrete counts (0-1023) to floating-point voltage (0-5V)
  float voltage = (rawValue * 5.0) / 1023.0;

  // Transmit telemetry over UART
  Serial.print("Raw: ");
  Serial.print(rawValue);
  Serial.print("  Voltage: ");
  Serial.print(voltage, 2);
  Serial.println(" V");

  delay(100);
}

Hardware registers governing prescaler (128 = 125kHz ADC clock) and reference voltage selection.

3

Mapping raw counts to floating-point values maintains full 10-bit decimal accuracy.

4

Transmits ASCII-encoded telemetry characters to the host machine over UART.

5
100ms Cadence

Samples at 10Hz, preventing serial buffer saturation while tracking physical knob motion.

analog_io.ino · production moving average
/*
 * Module: Analog I/O & Continuous Voltage Measurement
 * 10-reading circular moving average noise filter.
 */

const int ANALOG_PIN = A0;
const int NUM_READINGS = 10;

int readings[NUM_READINGS];
int readIndex = 0;
long total = 0;

void setup() {
  Serial.begin(9600);
  for (int i = 0; i < NUM_READINGS; i++) {
    readings[i] = 0;
  }
}

void loop() {
  // Subtract oldest sample from running accumulator
  total = total - readings[readIndex];

  // Sample new instantaneous reading
  readings[readIndex] = analogRead(ANALOG_PIN);

  // Accumulate new sample
  total = total + readings[readIndex];

  // Advance circular buffer index
  readIndex = (readIndex + 1) % NUM_READINGS;

  // Calculate filtered average
  int averageRaw = total / NUM_READINGS;
  float voltage = (averageRaw * 5.0) / 1023.0;
  int percentage = map(averageRaw, 0, 1023, 0, 100);

  Serial.print(averageRaw);
  Serial.print("\t");
  Serial.print(voltage, 2);
  Serial.print(" V\t");
  Serial.print(percentage);
  Serial.println("%");

  delay(100);
}
