Core Architecture

The PWM Synthesis Principle

Microcontrollers cannot generate true intermediate analog voltages natively without external Digital-to-Analog Converters (DACs). PWM solves this elegantly.

⚡

Rapid Binary Switching

Pulsing between 0V and 5V at 490 times per second creates an average effective potential proportional to the ON-time window.

📐

Duty Cycle Math

Defined as D = Ton / (Ton + Toff). 8-bit registers quantize this into discrete integer slices from 0 (0%) to 255 (100%).

👁️

Human Eye Perception

Human vision is logarithmic, not linear. A raw 50% duty cycle appears ~75% bright. Gamma 2.2 correction restores natural smooth dimming.

The Key Equation: Veffective = VCC × (analogWrite_Value / 255.0). At 128/255, the effective average voltage is 2.51 Volts.

Photometry Deep Dive

The Gamma 2.2 Biological Correction

Why naive linear fading looks jerky and stepped at low brightness levels.

Human eyes possess high dynamic sensitivity in dark environments to detect subtle silhouettes. This biological response follows Stevens' Power Law:

Perceived ∝ Measured0.45

Linear increases in voltage (0V → 1V → 2V) appear as massive jumps in perceived brightness.

PWM = (sin(angle) × 0.5 + 0.5)2.2 × 255

By applying an inverse power curve of gamma 2.2:

  • Spends 70% of time softly modulating low light values.
  • Decelerates smoothly at the peak and trough.
  • Produces an organic, breathing aesthetic like high-end consumer electronics.

Microcontroller Firmware Implementation

From direct duty control to non-blocking trigonometric organic breathing.

pwm_basic.ino 
/* Basic PWM LED Dimmer */

const int PWM_PIN = 9;

void setup() {
  pinMode(PWM_PIN, OUTPUT);
}

void loop() {
  // 25% Duty Cycle (~1.25V average)
  analogWrite(PWM_PIN, 64);
  delay(1000);

  // 50% Duty Cycle (~2.50V average)
  analogWrite(PWM_PIN, 128);
  delay(1000);

  // 100% Full On (5.00V)
  analogWrite(PWM_PIN, 255);
  delay(1000);
}

🔎 Register & API Analysis

1
analogWrite(9, val)

Sets the Output Compare Register 1A (OCR1A). Hardware timer automatically handles pin toggling.

2
255 Full Scale

Passing 255 forces pin continuously HIGH; passing 0 keeps pin continuously LOW without timer interrupts.

3
pow(sinVal, 2.2)

Applies gamma compensation curve matching human retinal rod/cone photopic response.

4
Non-Blocking Cadence

Advances trigonometry angle every 20ms using millis(), allowing other loop tasks to run concurrently.

5
490Hz Carrier

Sufficiently high to prevent human flicker fusion perception (critical threshold ~60Hz).

pwm.ino · production gamma 2.2 breathing controller
/*
 * Module: Pulse Width Modulation (PWM) & Breathing Glow
 * Trigonometric sine-wave with gamma 2.2 non-blocking cadence
 */

const int PWM_PIN = 9;

unsigned long previousMillis = 0;
const long interval = 20; // 50 Hz frame refresh

float angle = 0.0;

void setup() {
  pinMode(PWM_PIN, OUTPUT);
  Serial.begin(9600);
  Serial.println(F("PWM Breathing Controller Online on Pin 9."));
}

void loop() {
  unsigned long currentMillis = millis();

  if (currentMillis - previousMillis >= interval) {
    previousMillis = currentMillis;

    // Scale sinusoidal -1.0..+1.0 into normalized 0.0..1.0 range
    float sinVal = (sin(angle) + 1.0) / 2.0;

    // Gamma 2.2 perceptual scaling
    int brightness = (int)(pow(sinVal, 2.2) * 255.0);

    analogWrite(PWM_PIN, brightness);

    angle += 0.04;
    if (angle >= 2 * PI) {
      angle = 0.0;
    }
  }
}
