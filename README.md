# ⚡ Arduino Projects Cookbook

> **A modular, mix-and-match collection of Arduino building blocks — from a single blinking LED to full automation systems.**

This isn't just a repository of finished projects. It's a **cookbook** — every folder is a recipe, and every recipe is designed to be picked up, understood, and combined with others to build something entirely your own.

Whether you're a curious beginner or an experienced maker, start anywhere. Read the code, wire it up, make it blink, and then ask *"what happens if I add a sensor to this?"*

## 🍳 How to Use This Cookbook

Think of each sub-folder as a **recipe card**:

1. **Read the README** — Every project has a plain-English explanation of what it does and why.
2. **Check the components list** — See exactly what hardware you need.
3. **Look at the wiring diagram** — ASCII art + a pin table so nothing is ambiguous.
4. **Open the `.ino` file** — The code is commented line-by-line, not just at the top.
5. **Try the extensions** — Each recipe ends with "Try it yourself" challenges to push further.
6. **Mix with other modules** — Every project links to the others it pairs well with.

## 🛠️ Tools You'll Need

- **Arduino IDE** (v2.x recommended) — [Download here](https://www.arduino.cc/en/software)
- **Arduino Uno** (most sketches target Uno; notes given for Nano/Mega/ESP32 where relevant)
- A breadboard, jumper wires, and the components listed in each project
- A USB-A to USB-B cable
